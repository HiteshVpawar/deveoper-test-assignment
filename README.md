# Product Listing Assignment

## Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB

## Features
- Product listing with images, price & description
- Add to Cart functionality with cart count
- Search with debouncing
- Sort by price
- Responsive design
- Cart page with GST calculation
- API integration using Axios
